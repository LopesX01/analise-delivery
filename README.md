# Analise de Delivery - Tempo e Avaliação

Projeto de Análise de Dados com 3000 pedidos simulados.

### Problema resolvido
Analisei quanto tempo o delivery demora por bairro e qual tipo de restaurante é melhor avaliado.

### O que fiz
- Limpeza de dados com Pandas
- Calculo de tempo médio, mediana e top bairros com atraso
- Analise se cupom influencia na nota
- Dashboard no Power BI com tempo por região e nota média

### Tecnologias
Python, Pandas, Power BI, Excel

### Como rodar
python analise.py
